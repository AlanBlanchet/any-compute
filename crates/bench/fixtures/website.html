Why any-compute? Built from scratch for maximum hardware utilisation across every target.
Hardware-Agnostic Compute One trait dispatches to CPU SIMD, CUDA, ROCm, Metal, or WebGPU — the best path is chosen automatically based on runtime detection.
Arena DOM Engine Cache-friendly arena allocation, flexbox layout, CSS parsing, and hit-testing — 15x faster than heap-per-node browser DOMs.
Native GPU Rendering Instanced wgpu draw calls with glyphon text shaping. 60+ FPS at 50,000 primitives on integrated graphics.
Universal Bindings Auto-generated React, Vue, Svelte, Angular, Python, Node, Java, and WASM bindings from a single Rust source of truth.
Animation Engine Transition system with 7 easing curves, spring physics, and keyframe animations — all running at kernel throughput speeds.
Data Virtualisation Scroll through 100M rows at 60 FPS with virtual windowing. Only visible rows are laid out, styled, and rendered.
